# App Fit One

App fitness da academia Fit One Manaus: treino prescrito pelo personal, modo treino, evolução e comunidade.
Projeto de portfólio de Victor Mendes. Marca Fit One usada com autorização da academia.

**Stack:** Expo (React Native) + TypeScript + Expo Router · Supabase (próximas etapas)

## Rodar
```
npm install
npx expo start
```
Abra o QR code com a câmera do iPhone (Expo Go) ou pelo app Expo Go no Android.
